# Распределение дефицита

Программа распределяет запас товара между заявками. Она учитывает приоритет,
минимальную партию и кратность отгрузки. Для запуска нужен Python 3.10 или новее.
Сторонние библиотеки для расчёта не нужны.

## Запуск

Из папки проекта выполните команду

```sh
python run.py
```

Для других данных можно указать папку с двумя CSV

```sh
python run.py --data-dir path/to/data
```

В исходных данных семь кейсов. Для шести программа выводит отгрузки и остаток.
CASE_03 отклоняется, поскольку в нём есть отрицательный спрос и нулевая кратность.
Остальные кейсы продолжают рассчитываться. Полный вывод сохранён в `RESULTS.txt`.

Код завершения 0 означает, что ошибок нет. При ошибках программа возвращает 1.
Если повреждена структура CSV или отсутствуют обязательные столбцы, чтение
останавливается. Ошибки значений обрабатываются отдельно для каждого кейса.
Дополнительные столбцы допускаются.

## Как распределяется товар

Сначала обслуживаются заявки с приоритетом 1, затем 2 и далее. Больше
запрошенного не отгружаем. Если ограничения не позволяют выдать положительную
партию, заявка получает ноль.

Внутри одного приоритета рассчитываем доли пропорционально спросу. Бюджет группы
ограничен остатком склада и суммой допустимых максимумов. Заявки, для которых
вообще нет допустимой положительной партии, в расчёте долей не участвуют.

Каждую долю округляем вниз до кратности. Если она меньше минимальной партии,
сначала выдаём ноль. Затем добавляем допустимые партии тем, кто сильнее отстаёт
от своей целевой доли. При равном отставании выбираем меньший `request_id`
в лексикографическом порядке. Отставание может стать отрицательным.

Если старшим заявкам больше нельзя добавить ни одной партии, остаток переходит
следующему приоритету. Нераздаваемый остаток остаётся на складе.
Доли сравниваются точно через Fraction. Порядок строк не влияет на результат.

## Тесты

Можно создать отдельное окружение командой `python -m venv .venv`.
После его активации установите pytest и запустите проверки

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Для установки pytest нужен доступ к PyPI. Есть проверки всех исходных кейсов,
собственные примеры и 300 наборов с фиксированным seed. Описание каждой тестовой
функции объясняет, какое поведение она фиксирует и что нарушится при его изменении.

## Состав проекта

- `allocator.py` содержит модель заявки и алгоритм.
- `run.py` читает CSV и выводит результаты.
- `data/` содержит исходные данные без исправлений.
- `tests/` содержит тесты алгоритма и чтения данных.
- `REPORT.md` объясняет решения и ограничения.
- `DEFENSE.md` содержит разбор примеров для устной защиты.
- `RESULTS.txt` содержит вывод на исходных данных.
- `VALIDATION.md` описывает выполненные проверки.
